De Ctrl-serie

Een reeks open-source Android-apps om mijn eigen servers te beheren. Ze zijn privacyvriendelijk, zonder Google of tracking, en verspreid via een eigen F-Droid-repository die automatisch bouwt met GitHub Actions.

Eerlijk over hoe deze apps gemaakt zijn: de code is geschreven door Claude AI. Ik bepaal wat elke app moet doen en hoe ze eruitziet, ik test alles op mijn eigen toestellen en servers, en ik controleer de code. Zelf leren programmeren is mijn volgende doel, en AI is daarbij mijn leraar.
